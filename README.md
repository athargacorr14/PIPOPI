# PiPOPi — Sweet Things, Happy Days

Website storefront PiPOPi dibuat menggunakan HTML, CSS, dan JavaScript murni.

**Paket ini hanya berisi website publik desktop dan mobile. Admin dashboard tidak dibuat.**

## Menjalankan
1. Ekstrak file ZIP.
2. Buka folder `pipopi-store-website` di VS Code.
3. Jalankan `index.html` menggunakan Live Server.

## Fitur
- Homepage hero dan navigasi responsive
- Produk best seller dengan wishlist interaktif
- Pencarian produk
- Keranjang belanja dengan tambah/hapus item dan total otomatis
- Checkout diarahkan ke WhatsApp
- Promo dan kode diskon
- Informasi toko dan kategori produk
- Tentang PiPOPi
- Newsletter demo
- Footer dan bottom navigation untuk mobile

## Konfigurasi sebelum dipublikasikan
- Ganti nomor WhatsApp contoh `6281234567890` di `script.js` dengan nomor resmi toko.
- Verifikasi alamat, jam operasional, akun media sosial, harga dan detail produk pada `index.html`.
- Foto saat ini menggunakan URL Unsplash; ganti dengan foto produk resmi PiPOPi agar sesuai katalog sebenarnya.
- Newsletter hanya demo frontend, belum terhubung ke layanan email/database.
- Keranjang tersimpan sementara selama halaman terbuka; belum memakai database atau payment gateway.
